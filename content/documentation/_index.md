## Overview

This documents a **[fork of Tegola](/documentation/about-this-fork/)**. Tegola itself is created and
maintained by the [Go Spatial](https://github.com/go-spatial) team; its official documentation is at
[tegola.io](https://tegola.io). Read [About this fork](/documentation/about-this-fork/) first — it
lists what is added and the three ways this fork's behaviour differs from upstream.

Keep in mind Tegola is pre-1.0 so these docs are constantly changing to keep up-to-date with code
changes.
