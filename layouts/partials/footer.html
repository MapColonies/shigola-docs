These docs describe a fork of Tegola, hosted on GitHub. It adds OGC API - Tiles, multiple tile matrix sets and a layered cache — see About this fork.

Tegola is created and maintained by the Go Spatial team working (mainly) out of sunny San Diego. Upstream code is hosted on GitHub and documented at tegola.io, under the liberal MIT license. This fork is MIT licensed too, and all credit for Tegola belongs upstream.
