## Overview

This documents a **[fork of Tegola](./about-this-fork.md)**. Tegola itself is created and
maintained by the [Go Spatial](https://github.com/go-spatial) team; its official documentation is at
[tegola.io](https://tegola.io). Read [About this fork](./about-this-fork.md) first — it
lists what is added and the two ways this fork's behaviour differs from upstream.

Keep in mind Tegola is pre-1.0 so these docs are constantly changing to keep up-to-date with code
changes.
